## Data and derived outputs

`data/Input_USACH.xlsx` contains the consolidated municipal input used by the
analysis. `data/Output_USACH.xlsx` contains derived tables generated by the
pipeline. The data originate from public SINIM and FIGEM administrative
records; the repository license does not grant rights beyond those applicable
to the original sources.

Before making this repository public, confirm that redistribution of the
consolidated workbook, derived output workbook, figures and methodological
document is permitted by the applicable SUBDERE/SINIM source terms. If
redistribution is not permitted, publish the code and metadata while replacing
the workbooks with a documented download-and-rebuild procedure.

## Publication

DOI: <https://doi.org/10.35588/qezhpj36>

The 70/30 hybrid redesign mentioned in the article is a policy hypothesis, not
an implemented rule. It requires distributive simulation and institutional
